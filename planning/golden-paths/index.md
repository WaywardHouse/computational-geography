# Golden Path Pilots

## Purpose

This directory holds early pilot drafts for the `golden paths` concept proposed in
[`planning/golden-paths-framework.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/golden-paths-framework.md).

These are not yet public-facing pages.

They are working planning drafts designed to test whether the framework can do three things well:

- help problem-first readers enter the project
- connect distributed chapters into coherent workflows
- stay concrete without pretending there is only one valid modelling route

## Current Pilot Set

1. [`urban-flood-screening.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/golden-paths/urban-flood-screening.md)
2. [`trade-corridor-bottlenecks.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/golden-paths/trade-corridor-bottlenecks.md)

## What To Evaluate

As these pilots are reviewed, the main editorial questions are:

1. Does the template feel useful and repeatable?
2. Does the workflow stay concrete enough to guide a reader?
3. Does the path connect naturally to existing chapter families?
4. Does the distinction between minimum viable workflow and advanced branching feel clear?
5. Does the tone fit the rest of the planning and series architecture?

## Likely Next Additions

If these pilots work, the next likely candidates are:
