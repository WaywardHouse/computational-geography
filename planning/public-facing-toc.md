# Public-Facing Table of Contents

## Purpose

This document proposes a new beginner-friendly public structure for the flagship `Computational Geography` book.

It is based on the chapter classifications in [`planning/chapter-inventory.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/chapter-inventory.md) and the broader editorial direction captured in the planning documents in this repository.

It should now be read alongside [`planning/series-architecture.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/series-architecture.md) and [`planning/site-architecture.md`](/Users/pauldhobson/src/websites/waywardhouse-computational-geography/planning/site-architecture.md).

The goal is:

- preserve the original ENVMOD209-style teaching promise in one coherent main book
- make the on-ramp dramatically easier
- clarify the main learning journey
- separate essential reading from deeper optional material
- avoid treating every strong chapter as part of one mandatory continuous textbook

## Editorial Model

Inside the flagship book experience, the public-facing structure should still have three visible layers:

1. `Core Book`
2. `Topic Libraries`
3. `Laboratory`

At the series level, this means:

1. `Computational Geography` remains the main book
2. specialist branches can later become companion volumes
3. advanced investigations remain a laboratory line rather than part of the beginner staircase

At the site level, these layers should sit inside a clearer Earthdata-like cluster model:

1. `Start Here`
2. `Core Book`
3. `Topic Libraries`
4. `Laboratory`
5. `Methods and Tools`

### Core Book

This is the main staircase for smart Grade 10 readers and up.

It should be the most visible path on the Learn landing page.

### Topic Libraries

This contains specialist branches that are better browsed by subject without interrupting the beginner-safe spine.

### Laboratory

This contains advanced investigations, project-style chapters, and companion material.

## Proposed Public Structure

Recommended public-facing structure:

1. `Getting Started`
2. `Maths for Modelling Space`
3. `Earth Systems and Observation`
4. `Part 3: GIS and Spatial Analysis`
5. `Hazards, Change, and Prediction`
6. `Cities, Networks, and Economic Geography`
7. `Advanced Investigations`

This is a publishing structure, not a deletion structure.

The existing material is retained, but the reader is no longer asked to treat all of it as one continuous mandatory path.

Just as importantly, the flagship book is no longer being asked to carry every branch of the wider project as though they are all equally central to the first reading experience.

At the site-navigation layer, this also means not forcing every branch to masquerade as a numbered book part.

## Reader Promise

The book should be able to say, clearly:

- start here if you are new
- follow the core path if you want the main journey
- open topic libraries when you want subject depth
- use the laboratory when you want advanced projects

At the series level, the project should also be able to say:

- this book is the main ENVMOD209-inspired modelling text
- remote sensing, cryosphere, economic systems, and advanced methods can grow into companion works

### Special Editorial Issue

This part currently contains parallel pipeline chapter families:

- Alberta-specific infrastructure chapters

This is the clearest sign that the material is outgrowing a single-book container.

The flagship book should likely keep only the gateway human-systems chapters and move the deeper infrastructure families into a companion line.

## Likely Companion Extractions

These are not deletions.

They are the most likely future companion branches:

- `Remote Sensing for Environmental Modelling`
- `Cryosphere and Mountain Systems`
- `Economic Geography and Infrastructure Systems`
- `Geographic Machine Learning and Inference`

The flagship TOC should be designed so those extractions can happen cleanly later without breaking the logic of the main book.

These should be reviewed and likely presented as:

- `core concept`
- `case study`
- `advanced application`

rather than as one undifferentiated sequence.

## Advanced Investigations

### Role

This is the home for specialist, project-style, and advanced applied material.

It should be framed as a studio or lab collection, not as required sequential reading.

### Contents

- `Advanced Remote Sensing`
- `Cryosphere and Mountain Systems` if not already surfaced as a topic library
- `Machine Learning for Geographic Data`
- `Computational Geography Laboratory`
- deeper environmental modelling extensions
- advanced statistical and numerical methods

### Laboratory Chapters

The current Laboratory section should live here essentially intact, but with revised framing:

- investigations
- projects
- notebooks
- companion chapters

not:

- required mainline textbook sequence

## Topic Libraries Structure

The `Topic Libraries` layer should be visible and organized, not hidden.

Recommended topic-library groupings:

- `Earth Observation and Orbits`
- `Biogeochemical Cycles`
- `Advanced Remote Sensing`
- `Cryosphere and Mountain Systems`
- `Advanced Hazard Modelling`
- `Economic Systems in Depth`
- `Machine Learning and Statistical Methods`

This helps the reader feel invited deeper rather than excluded by a giant expert-only block.

## Manuscript-Equivalent Shape

If this were being shaped into an O'Reilly-adjacent print-style manuscript, the public-facing book should behave more like:

- `Part 0` plus `Parts 1-5` as the core manuscript
- `Advanced Investigations` and most topic-library material as companion web material

That gives a print-equivalent shape closer to:

- `35-50` core chapters
- strong progressive structure
- clear reader promise
- advanced material preserved but not overwhelming
